## 講義概要

WebAssembly (Wasm) は仮想的な命令セットです。ポータブルさを意識した仕様策定が行われており、Web ブラウザに限らず様々な環境で動作させることができます。サンドボックス環境で動作するため安全、とも言われています。

この講義では、Wasm の概念からそのしくみまでをハンズオン形式で学びます。Wasm の構造に最も近い、テキスト形式の Wasm を書くところから始めて、Wasm の中身がどのようになっているのか、Wasm ランタイムがどのように動作するのかを覗いていきます。

この講義の目標は以下の通りです。Web と低レイヤの世界に潜ってみませんか？

1. WebAssembly という切り口から Web 技術に触れる
2. バイナリという概念を知って、親しみを持つ
3. 「仕様書を読む」という選択肢を思い浮かべられるようになる
