## 講義概要

WebAssembly (Wasm) は仮想的な命令セットです。ポータブルさを意識した仕様策定が行われており、Web ブラウザに限らず様々な環境で動作させることができます。サンドボックス環境で動作するため安全、とも言われています。

この講義では、Wasm の概念からそのしくみまでをハンズオン形式で学びます。Wasm の構造に最も近い、テキスト形式の Wasm を書くところから始めて、Wasm の中身がどのようになっているのか、Wasm ランタイムがどのように動作するのかを覗いていきます。

この講義の目標は以下の通りです。Web と低レイヤの世界に潜ってみませんか？

1. WebAssembly という切り口から Web 技術に触れる
2. バイナリという概念を知って、親しみを持つ
3. 「仕様書を読む」という選択肢を思い浮かべられるようになる

### 事前課題

(A) WebAssembly の特徴のうち、あなたが「面白そう」「興味深い」と思うものはどれですか？また、それは何故ですか？

(B) WebAssembly 形式にコンパイルできるプログラミング言語を 1 つ選んで、以下に取り組んでください。なお、上手くできなかった・途中までしか出来なかった場合も、どこまでやったのか、何をしたのか、どう上手くいかなかったのかを書いてみてください。

(1) 選んだプログラミング言語について語ってください。語る内容の例：何故その言語を選んだのか、どのような特徴がある言語か、その言語が好きか嫌いか＆それは何故か、等（なんでもいいです！もちろん例の全てに回答する必要はありませんし、他のことについて語ってもかまいません）

(2) 選んだプログラミング言語を用いて「引数として数字を 2 つ受け取って、それらを足した数を返す」という関数を作ってください。書いたプログラムを答えてください。

(3) (2) で作成した関数を使って 1+2 を計算した結果を、標準出力に出力するプログラムを書いてください。そして、そのプログラムを WebAssembly 形式で出力してみてください。
書いたプログラムと、どうやって WebAssembly 形式として出力したかを答えてください。

(4) 出力したWasmを実行してみてください。何を使って、どのように実行したのか、実行結果はどうなったかを答えてください。
